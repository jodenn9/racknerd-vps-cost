## 外贸独立站主机，和普通网站主机的挑法有什么不同

差别集中在三处：机房位置、IP 形态、付款方式。

机房位置排第一。外贸独立站的访客在海外，网站放在国内服务器上，海外客户打开会明显变慢，所以做外贸基本默认选海外机房——目标客户在欧美，美国机房最顺手；客户集中在东南亚、日韩，或者想兼顾国内访问速度，香港机房才值得多花钱，不少香港服务器走 CN2+BGP 线路，和全球运营商的互联覆盖比较全。

IP 形态影响 SEO 的基础面。传统虚拟主机默认共享 IP，同一个 IP 上的其他站点出事可能牵连到你；独立 IP 没有这层风险，这也是老牌建站圈一直建议外贸站用独立 IP 的原因——要么在虚拟主机上加钱选购带独立 IP 的套餐，要么直接用一台自带独立 IPv4 的 VPS。

付款方式是很多攻略不写、但国内用户一定会撞上的问题：有的主机商收支付宝，有的只认 PayPal 和国际信用卡。下单前不确认这一点，购物车填到一半才发现付不了款，挺影响心情的。
